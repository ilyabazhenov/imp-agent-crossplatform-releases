IMP Agent

Gets to the bottom of a task instead of retelling it

Chat with a model, files, shell and git — with Jira, Confluence, Bitbucket, Jenkins, TestOps and Kubernetes right alongside. One window, on macOS and Windows.

Chat

Reads the code, the history and the logs — and tells you what it found

The agent opens files in your working folder, searches through them, checks git history and runs commands on its own. Every edit and every unfamiliar command asks for permission — with a diff you see before anything changes.

Every step in view

Reasoning, tool calls and their results sit in the feed in order: what the agent read, what it found and why it decided the way it did.

Nothing outside the folder

Tools stay inside the working folder, and writing to other systems — a comment, a build restart — asks you every time.

Plan mode

For bigger jobs the agent first lays out a plan with its risks — and gets to work only once you approve it.

TestOps

A red test run gets investigated right where you see it

Launches, failures, step-by-step scenarios, result history and defects — all in one place, and a single button hands the whole run to the chat, not just a link to it.

Bitbucket

Code review with the diff and the comments

Pull requests for your working folder’s repository, merge status, builds per commit and comment threads. Reply to a comment right here — or ask the agent whether it still applies, and it will go and check the code itself.

Kubernetes

Deployments, pods and logs — without switching to a browser

Deployment status per namespace, failing pods, events and the tail of the log. Secrets and connection strings sit behind a separate checkbox — the agent can’t see them until you allow it.

Jira and Confluence

The whole issue, not just its title

Description, comments, links, attachments and change history — in the same window. The agent reads them itself and can write back: a comment, a status change, a new issue — always showing you the full text before it is sent.

MCP

The same tools, in the editor you already love

Cursor, Claude Code and Codex can reach Jira, Bitbucket, Jenkins, TestOps, Confluence and your cluster straight from their own window — with the same tools the agent uses here. Your tokens stay in the app: the client never needs to know them or configure a single URL.

Off by default

Until you flip the switch, nothing is exposed. Services are enabled one by one with checkboxes.

Writes only with your permission

A comment on an issue, a build restart, a config change — each one asks in this window, naming the client.

See who asked for what

The server log shows the client, the call, its duration and the response — along with the request and response bodies.

Under the hood

Your model, your network, your disk

Bring your own model

Any OpenAI-compatible gateway by URL and key — or the Claude Code or Codex you already have, on your existing subscription, with no second bill.

Everything stays on your machine

Conversations, attachments and logs live on your disk, keys in the system keychain. The only thing that leaves is what you send to the model.

Updates itself

The app checks for new versions in the background and installs them in one click — after asking, never silently.

Install

Download and install

The app checks for new versions on its own and offers to install them in one click. Installing means a restart: an unfinished turn is interrupted, your conversations stay where they are.

macOS

  1. Download the archive for your processor and double-click it to unpack.
  2. Drag ImpAgent into Applications — exactly there, otherwise the updater has nowhere to write the new version.
  3. On first launch macOS will say the app is damaged. It isn’t: the system simply won’t vouch for a publisher it doesn’t know. Run this once in Terminal: 
xattr -dr com.apple.quarantine /Applications/ImpAgent.app
IMP Agent for Apple Silicon M1 and newer IMP Agent for Intel Macs from before 2020

Windows

  1. Download the installer and run it.
  2. SmartScreen will show a blue “Windows protected your PC” window — click “More info”, then “Run anyway”. The installer isn’t signed, and that is expected.
  3. No administrator rights needed.
IMP Agent Setup 64-bit Windows

Not every version ships for both systems. If the latest release has no Windows file, take the one from the previous release — the update will arrive with the next one.

License

After installation the window shows a machine code — send it over, and you’ll get an activation string back. Verification is offline: no license server and no internet connection needed to run. A license is valid through the stated date inclusive and can be renewed in advance.

Credentials

The model key and service tokens are stored encrypted by the operating system and are never handed back to the window. They are scrubbed from the logs at every level of detail.
